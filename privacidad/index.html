Política de tratamiento de datos

La confidencialidad es la base de nuestro trabajo. Aquí explicamos cómo tratamos la información que compartes con nosotros al contactar a Quórum Risk.

Actualizada el 18 de noviembre de 2026.

Quién gestiona este sitio

Quórum Risk es la marca que opera este sitio y recibe consultas comerciales desde Bogotá, Colombia. Para asuntos de datos personales, solicitudes de información o ejercicio de derechos, escríbenos a contacto@quorumrisk.co.

No necesitamos que compartas datos de clientes, bases de cartera ni información sensible para agendar una primera reunión.

Qué información recibimos y para qué

Consultas y reuniones

Si nos escribes o agendas una reunión, podemos recibir tu nombre, correo electrónico, empresa, cargo, los datos de contacto y el mensaje que decidas compartir.

Utilizamos esa información para responder tu solicitud, organizar la reunión y valorar una posible relación comercial.

Proyectos contratados

Si acordamos trabajar juntos, definimos por contrato qué información necesitamos, con qué finalidad, quién puede acceder y cómo se protege. No solicitamos bases de cartera mediante esta página.

Los casos técnicos publicados utilizan datos sintéticos o públicos.

Servicios externos y protección

Para gestionar reuniones utilizamos un enlace a Cal.com, que opera fuera de este sitio. Al utilizar su servicio también se aplican sus condiciones y política de privacidad. El alojamiento de esta web se realiza mediante GitHub Pages y se cargan tipografías desde Google Fonts.

Limitamos el uso de los datos de contacto a las finalidades descritas, evitamos solicitar información sensible en la etapa comercial y acordamos medidas adicionales de confidencialidad y acceso antes de recibir datos de una cartera.

Los proveedores tecnológicos pueden tratar información técnica necesaria para prestar sus servicios. No vendemos bases de datos personales ni publicamos datos de clientes sin autorización.

Conservación y derechos

Conservamos la información de contacto durante el tiempo necesario para atender la consulta, gestionar la relación comercial y cumplir las obligaciones aplicables. Cuando ya no es necesaria, procedemos a eliminarla o dejar de utilizarla según corresponda.

Puedes solicitar acceso, actualización, corrección o eliminación de tus datos, y presentar consultas o reclamos relacionados con su tratamiento, escribiendo a contacto@quorumrisk.co. Atenderemos tu solicitud conforme a la normativa aplicable.

Esta política se refiere al contacto comercial a través de quorumrisk.co. Un proyecto con acceso a datos de terceros requiere acuerdos específicos y una revisión de las obligaciones de cada parte.
